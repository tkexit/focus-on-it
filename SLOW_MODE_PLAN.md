# Slow Mode — Claude Code Plan v1.0

## Контекст проекта

Slow Mode — отдельное пространство для инженеров, которые работают с AI-инструментами и теряют ощущение ориентира. Не рабочий инструмент, не productivity-app. Место, где можно выдохнуть и увидеть горизонт.

**Ощущение, которое продукт должен давать:**
- Видимость: я вижу, где я, что для меня важно
- Тишина: убрано всё лишнее

**Два режима использования:**
- Утро: ритуал 5–10 минут, обновить "сейчас", посмотреть на горизонт
- Выдох: открыть в любой момент, когда срывает — просто посмотреть

---

## Что строим (MVP)

Веб-приложение. Один главный экран. Два слоя:

1. **Горизонт** — одна главная цель. Меняется редко. Всегда видна.
2. **Сейчас** — где я нахожусь. Короткая заметка. Меняется каждый день.

Из этого естественно вырастает лёгкий **план** — не список задач, а понимание следующего шага.

Заметки сохраняются локально (localStorage). Никакого бэкенда на MVP.

## Дизайн

### Принципы
- Много пустого пространства — тишина должна быть видна
- Одна мысль на экране в каждый момент
- Никаких кнопок без причины, никаких панелей, никаких иконок
- Типографика — главный элемент

### Палитра
```css
--bg: #F5F2EC;          /* тёплый офф-вайт, как бумага */
--text-primary: #1A1814; /* почти чёрный */
--text-secondary: #8C8070; /* тёплый серый */
--accent: #2D4A3E;       /* глубокий зелёный — горизонт */
--border: #E0DAD0;
```

### Типографика
- Display / заголовки: `Playfair Display` или `Cormorant Garamond` — editorial, медленная
- Body: `iA Writer Quattro` или `Lora` — читаемая, спокойная
- Размер горизонта: большой, занимает пространство

### Макет главного экрана
```
[пустое пространство]

  Горизонт                     ← большой, тихий
  ─────────────────────────
  Твоя главная цель здесь      ← одна строка или две, крупно

[немного пространства]

  Сейчас                       ← меньше, но заметно
  ─────────────────────────
  Где ты находишься             ← текст-поле, свободный ввод

[пространство]

  Следующий шаг                ← совсем тихо, почти шёпотом
  ─────────────────────────
  Что важно сделать сегодня

[пустое пространство]

                           [·]  ← единственная кнопка: войти в режим редактирования
```

## Типы данных

```typescript
interface SlowModeState {
  horizon: {
    text: string;
    updatedAt: string;
  };
  now: {
    text: string;
    date: string;           // YYYY-MM-DD — обновляется каждый день
  };
  plan: {
    text: string;
    date: string;
  };
  history: NowEntry[];      // предыдущие записи "сейчас"
}

interface NowEntry {
  text: string;
  date: string;
}
```

## Поведение

### Горизонт
- Отображается крупно, всегда
- Редактируется кликом (inline edit или тихий modal)
- Если не задан — плейсхолдер: *"Что для тебя сейчас важнее всего?"*
- Сохраняется до явного изменения

### Сейчас
- Каждый день — новая запись (определяется по дате)
- Если уже есть запись за сегодня — показывает её, можно редактировать
- Если новый день — поле пустое, предыдущая запись уходит в history
- Плейсхолдер: *"Где ты сейчас относительно горизонта?"*

### План
- Свободный текст, меняется свободно
- Не структурированный список — просто заметка

### История
- Не показывается по умолчанию
- Доступна через тихий toggle или свайп — "назад"
- Показывает предыдущие записи "сейчас" по датам

## Шаги сборки (в порядке)

```
1. Инициализация проекта
   → vite create slow-mode --template react-ts
   → установить зависимости

2. useStorage hook
   → get/set/clear для SlowModeState
   → авто-определение нового дня для Now

3. Компонент Horizon
   → отображение + inline edit
   → анимация появления (fade in, медленная)

4. Компонент Now
   → textarea без рамок
   → автосохранение по debounce (500ms)
   → определение нового дня

5. Компонент Plan
   → аналогично Now, но проще

6. Главный экран App.tsx
   → сборка всех компонентов
   → типографика и spacing

7. Стили
   → CSS variables
   → шрифты через Google Fonts
   → тишина через whitespace

8. История
   → toggle внизу экрана
   → список предыдущих Now по датам

9. Финальный polish
   → fade-in при загрузке
   → плавные переходы при редактировании
   → responsive (мобайл тоже важен)
```
